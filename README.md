# My Notepad — 4.0 Ink & Lecture

Бесплатный PWA-блокнот для рукописных конспектов с локальным хранением и работой офлайн.

**[Открыть My Notepad](https://daniilka-msu.github.io/my-notepad-ipad/)**

## Установка и главное в текущей версии

| Устройство | Как установить |
| --- | --- |
| iPad | Откройте приложение в Safari → «Поделиться» → «На экран Домой» → «Добавить». Если есть переключатель «Открывать как веб-приложение», включите его. |
| iPhone | Откройте приложение в Safari → меню «Поделиться» → «На экран Домой» → «Добавить». Название и расположение меню зависят от версии iOS. |
| Android | Откройте приложение в Chrome → меню ⋮ → «Добавить на главный экран» → «Установить». Если предлагается только ярлык, используйте доступный вариант браузера. |

Это установка из браузера. Сначала полностью загрузите приложение с интернетом, затем открывайте его с иконки. Основной интерфейс рассчитан на iPad; установка на телефон не означает, что все функции проверены на физическом iPhone или Android.

Инструкции браузеров: [Apple — iPad](https://support.apple.com/en-mide/guide/ipad/ipad8f1f7a29/ipados), [Apple — iPhone](https://support.apple.com/guide/iphone/iphea86e5236/ios), [Google — Android](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=ru).

Что доступно:

- **Рукописное письмо:** разные ручки и кисти, маркер, два ластика, сглаживание, Undo/Redo, избранные инструменты Pen Dock. Поддерживаются палец, обычный ёмкостный стилус и события Apple Pencil; давление используется, когда устройство передаёт достоверные данные пера.
- **Чёткое письмо при увеличении:** отрисовка с учётом плотности экрана и «Окно письма» с увеличением 2×–6×. Масштаб листа не меняет положение клеток относительно записей.
- **Редактируемые объекты:** текст, изображения с обрезкой, фигуры, формулы, таблицы, диаграммы, графики функций и блок-схемы. Добавление — через меню «Вставить», оформление — в панели выбранного объекта.
- **Учебная библиотека:** тетради, папки, избранное, поиск, корзина с восстановлением, светлая и тёмная темы, клетка 5/7/10 мм.
- **Документы:** импорт PDF и изображений, аннотации, экспорт PNG и PDF через системную печать, JSON-копии заметок.
- **Лекции:** локальная запись звука, пауза, закладки, воспроизведение и отдельный экспорт. Расшифровка подключается отдельно через собственный сервер; полученный текст можно редактировать, искать и экспортировать в TXT/SRT.

## Быстрый старт

1. На домашнем экране создайте тетрадь или импортируйте PDF/изображение.
2. Выберите ручку на панели письма. Для обычного стилуса оставьте режим «Любой стилус и палец» в настройках.
3. Для объектов откройте «Вставить». Для увеличенного ввода нажмите «Окно письма», для аудио — «Лекция» внизу редактора.
4. Настройки находятся в правом верхнем углу: «Письмо», «Бумага», «Интерфейс», «Василий», «Данные».

## Сохранение, офлайн и ограничения

Заметки и вложения хранятся локально в IndexedDB. Автосохранение запускается после 3 секунд без изменений и активного ввода; есть контрольный интервал 10 минут и индикатор ошибок с повторной попыткой. Старые заметки сохраняют прежние координаты и разлиновку до явного изменения пользователем.

После загрузки ресурсов письмо и редактирование работают офлайн. Автоматической синхронизации между устройствами нет. Регулярно экспортируйте резервные копии: браузер может освободить локальное хранилище. JSON-копия включает заметки и изображения, **но не аудиозаписи и расшифровки** — их нужно экспортировать отдельно. Восстановление JSON добавляет копии тетрадей, сохраняя существующие.

Для записи нужны HTTPS, разрешение микрофона и поддержка MediaRecorder. Запись в фоне или при блокировке экрана не гарантируется. PDF экспортируется через печать с растровым представлением страницы; исходная векторная структура импортированного PDF не сохраняется. Шрифты зависят от устройства. Аппаратное различение ладони и обычного ёмкостного стилуса браузеру недоступно.

Физические iPad, iPhone и Android в последнем цикле разработки не проверялись. Автоматические сценарии Chromium/Edge и WebKit не заменяют проверку Safari и стилуса на устройстве.

## Дополнительные сервисы

- **Василий:** по умолчанию не подключён. Нужны отдельный сервер, ключ провайдера и вход. [Настройка](server/README.md).
- **Расшифровка лекций:** подготовлен сервер faster-whisper с локальной моделью, паролем и явным согласием на передачу записи. Модель нужно установить отдельно; реальное распознавание с моделью в последней проверке не запускалось. [Настройка и ограничения](transcription/README.md).

## Разработка и документация

Статическое приложение на HTML, CSS и JavaScript: Canvas, IndexedDB, service worker. PDF.js, MathJax и Apache ECharts поставляются локально; лицензии библиотек находятся в `vendor/`. Серверные возможности подключаются отдельно.

Для локального запуска используйте HTTP-сервер, например `python -m http.server 8000`. Для публикации PWA нужен HTTPS. Открытие через `file://` не подходит. После обновления закройте все окна приложения и откройте его с интернетом; очищать данные сайта не нужно.

Основные проверки (Node.js 22+ и Edge; подробности окружения — в тестах):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run.ps1
node --test tests/server.test.mjs tests/groq.test.mjs
```
