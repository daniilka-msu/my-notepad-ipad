# Мои тетради — PWA для iPad

Бесплатный прототип рукописного блокнота: несколько тетрадей, страницы, ручка, маркер, ластик, undo/redo, клетка/линейка, экспорт через системную печать в PDF, офлайн-кэш.

## Запуск

В папке проекта: `python3 -m http.server 8000`, затем открыть `http://localhost:8000` на компьютере.

Для iPad разместить папку на HTTPS-хостинге (например, GitHub Pages или Netlify), открыть адрес в Safari → Поделиться → На экран «Домой».

Данные хранятся в localStorage конкретного браузера/устройства. Это прототип, а не надежное резервное хранилище: регулярно экспортируйте тетради в PDF. PDF импорт, распознавание почерка, синхронизация, полноценное подавление ладони пока не реализованы. Экспорт использует диалог печати Safari → Сохранить в файлы как PDF.

## Рисование на iPad

Рисуйте пальцем или Apple Pencil. Включите «Только Pencil», чтобы касания ладони не оставляли штрихи. В обычном режиме Pencil получает приоритет над активным касанием. Отмена системного ввода сохраняет уже нарисованную часть штриха. Формат локальных тетрадей не изменён.

Проверка на настоящем iPad: короткие точки и быстрые линии Pencil и пальцем, ладонь в режиме «Только Pencil», отмена/повтор, переход страниц, поворот экрана, перезапуск Safari и запуск с домашнего экрана без интернета. Прокрутка длинной страницы доступна за пределами листа.

## Документы и хранение

PDF, PNG, JPEG и WEBP импортируются через «Импорт» в отдельную тетрадь. PDF.js 6.4.299 (Apache-2.0, legacy-сборка) включена локально с worker, шрифтами, CMaps и WASM; CDN не нужен. Источник: https://mozilla.github.io/pdf.js/examples/index.html. На старых версиях iPadOS совместимость нужно проверить отдельно.

Фон PDF растеризуется постранично (длинная сторона до 1600 px); поверх него сохраняются редактируемые штрихи. Текст PDF извлекается для будущего анализа. «PDF» открывает системную печать: выберите сохранение в PDF. Экспорт включает фон и аннотации, но не сохраняет исходную векторную структуру, формы и ссылки документа.

Новые записи и фоны хранятся в IndexedDB. При первом запуске старые тетради переносятся из localStorage; исходный ключ `ipad-notebooks-v1` не удаляется. Обновление service worker затрагивает только кэш файлов приложения, не IndexedDB.

## Проверки

Node.js 22+ и Microsoft Edge: `powershell -NoProfile -ExecutionPolicy Bypass -File tests/run.ps1`. Тесты запускают временный локальный HTTP-сервер и изолированный профиль браузера, не обращаясь к пользовательским тетрадям. Проверяются ввод, темы, сглаживание, IndexedDB, изображения, двухстраничный PDF и компоновка аннотаций для экспорта.
