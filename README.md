# My Notepad iPad

Бесплатное PWA-приложение для рукописных заметок в Safari на iPad. Несколько тетрадей, страницы, ручка, маркер, два ластика, отмена/повтор, импорт документов, резервные копии и офлайн-работа.

Приложение: https://daniilka-msu.github.io/my-notepad-ipad/

## Письмо

В настройках (⚙) выберите режим ввода:

- **Любой стилус и палец** — режим по умолчанию; подходит неоригинальным стилусам, которые Safari определяет как касание.
- **Только стилус, если устройство позволяет его определить** — принимаются события `pointerType: pen`.
- **Apple Pencil** — также требует событий пера; браузер не гарантирует распознавание марки стилуса.

В области листа отключены системные жесты прокрутки, выделение и контекстное меню. Панели и подписи настроек не выделяются при письме; поля чата и прокрутка библиотеки сохраняют обычное поведение. Для прокрутки длинного листа используйте поля вокруг бумаги. Подавление ладони надёжнее при выборе режима пера; если стилус определяется как палец, приложение не может аппаратно отличить его от ладони.

Доступны обычная, шариковая, гелевая и перьевая ручки, цвет, толщина, непрозрачность, сглаживание (0 — выключено), пиксельный ластик и удаление целого штриха. Давление используется при передаче его в событиях пера; касания имеют постоянную толщину. Почерк не заменяется печатным текстом.

В настройках письма доступны «Без коррекции», «Лёгкое сглаживание» (по умолчанию для новых настроек), «Сбалансированное» и «Сильное», отдельная стабилизация и предпросмотр линии. Старое значение сглаживания сохраняется. Новые штрихи фильтруются один раз, без предсказания продолжения и повторного построения кривых; старые штрихи сохраняют прежний вид.

События объединённых выборок проверяются по указателю, типу и времени и упорядочиваются. Повторы, устаревшие и нечисловые координаты отбрасываются. Скачок более 160–300 экранных CSS-пикселей (порог зависит от интервала событий) завершает штрих без соединения; после него нужно снова коснуться листа. Координата отрыва дальше 32 CSS-пикселей от последней принятой точки игнорируется. Это защитные эвристики: очень быстрые движения при редких событиях требуют проверки на устройстве. Отмена указателя и потеря захвата сохраняют принятую часть штриха без добавления конечной точки.

## Интерфейс и бумага

Светлая, тёмная или системная тема; крупные кнопки, компактная панель, панель сверху/снизу, отображение библиотеки. Настройки сохраняются на устройстве.

Для каждой тетради выбираются клетка, линейка, точки или чистый лист; белая, кремовая, тёмно-серая или чёрная бумага; A4, A5 или квадратный формат. Для тёмной бумаги выберите светлое перо. Тема интерфейса и цвет бумаги независимы.

## Документы и PDF

Кнопка **Импорт** открывает системный выбор файлов Safari: PDF, PNG, JPEG, WEBP. Документ создаёт отдельную тетрадь. PDF импортируется постранично; фон и редактируемые штрихи сохраняются отдельно. Текст PDF извлекается для анализа, OCR сканов не выполняется.

Используется локальная legacy-сборка **PDF.js 6.4.299**, бесплатная лицензия Apache-2.0. Worker, шрифты, CMaps и WASM включены в репозиторий и офлайн-кэш. CDN не нужен. [Пример использования PDF.js](https://mozilla.github.io/pdf.js/examples/index.html). Поддержку конкретной старой версии iPadOS проверяйте на устройстве.

PDF растеризуется с длинной стороной до 1600 px, отдельные изображения — до 2400 px. **PDF** открывает системную печать с фоном и аннотациями: выберите сохранение в PDF. Экспорт не сохраняет исходную векторную структуру, формы, ссылки и редактируемый текст PDF. Очень большие документы требуют больше памяти; импорт и печать зависят от ограничений Safari.

## Данные и резервные копии

Автоматическое сохранение включено. Тетради находятся в **IndexedDB**; фоновые изображения хранятся как Blob отдельно от метаданных и штрихов. Импорт тетради и её фонов выполняется одной транзакцией. Статус сохранения отображается под страницей, ошибки не выдаются за успешное сохранение.

При первом запуске старые тетради переносятся из `localStorage` (`ipad-notebooks-v1`). Исходный ключ не удаляется, но новые изменения сохраняются только в IndexedDB. Если IndexedDB недоступна, приложение явно сообщает, что новые записи не сохраняются; экспортируйте их перед закрытием.

В разделе **Данные** доступны экспорт полной JSON-копии, импорт и сведения об объёме хранилища. Копия включает все тетради и фоны документов. Восстановление сначала проверяет файл и изображения, затем **добавляет копии с новыми идентификаторами**, сохраняя существующие тетради. Внешние настройки интерфейса автоматически не заменяются; копия содержит их для справки. Принимаются также старые JSON-файлы с объектом `{books, selected}` без фоновых документов. Лимит импорта копии — 250 МБ.

Браузер может освобождать локальное хранилище: регулярно сохраняйте копии в приложение «Файлы». Запрос долговременного хранения доступен, если его поддерживает Safari; браузер вправе отказать. Обновление service worker меняет только кэш файлов приложения, не пользовательскую базу.

## ИИ-помощник

Интерфейс поддерживает вопросы, объяснение тем, решения с пояснениями, краткий конспект, отправку изображения выбранной страницы и/или извлечённого текста документа, вставку ответа в новые страницы. Содержимое отправляется только после выбора вложения и нажатия «Отправить». Текст документа ограничен первыми 40 000 символами; для сканов можно отправить изображение страницы. История чата находится в памяти до перезагрузки.

По умолчанию отображается **«ИИ не подключён»**, запросы к GPT не имитируются. Нужны отдельный HTTPS-сервер, аутентификация и квоты. OpenAI API может оплачиваться отдельно. Ключ хранится только в серверном окружении, никогда в клиенте, localStorage или публичном репозитории.

Адаптер и контракт: [server/README.md](server/README.md). Публичная конфигурация `config.js` содержит только адрес сервера; изначально он пуст.

## Запуск и обновление

Разместите статические файлы на HTTPS-хостинге. Для локальной разработки подойдёт любой HTTP-сервер, например `python -m http.server 8000`, если установлен Python. Открытие через `file://` не подходит для worker PDF.js и PWA.

На iPad: Safari → Поделиться → На экран «Домой». После первой полной загрузки приложение и библиотека PDF работают офлайн. Новая версия кэша активируется после закрытия старых вкладок/PWA; после обновления закройте все окна приложения и откройте его с интернетом. Не очищайте данные сайта ради обновления.

## Проверки

Требуются Node.js 22+ и Microsoft Edge (или путь к Chromium в переменной `EDGE_PATH`).

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run.ps1
node --test tests/server.test.mjs
node --check app.js
node --check documents.js
node --check storage.js
node --check backups.js
node --check assistant.js
node --check sw.js
```

Тесты создают временный локальный HTTP-сервер и изолированный профиль браузера. Они проверяют старые заметки и миграцию, ввод и режимы стилуса, темы, сглаживание, IndexedDB, настоящий двухстраничный PDF, изображения, экспорт с аннотациями, неподключённый ИИ, вставку текста, резервные копии, восстановление без замены данных, перезагрузку и офлайн-запуск. Серверные тесты не обращаются в OpenAI и не используют реальные ключи.

На настоящем iPad проверьте неоригинальный стилус и Apple Pencil, ладонь, быстрые линии и точки, все настройки, поворот экрана, выбор PDF из «Файлов», печать с аннотациями, восстановление копии и запуск PWA без сети. Автоматические проверки Edge не заменяют Safari и аппаратные испытания.
