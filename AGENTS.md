# Инструкции для работы над my-notepad-ipad

1. Всегда общайся с пользователем на русском языке.
2. Самостоятельно изучай код и вноси необходимые изменения для выполнения задачи.
3. Пиши понятный, поддерживаемый код без неоправданного усложнения.
4. Сохраняй совместимость с iPad, Safari, пальцевым вводом, обычными сторонними стилусами и Apple Pencil.
5. Не ломай существующие функции рисования, сохранения заметок, импорта, экспорта и офлайн-режима.
6. После изменений самостоятельно запускай доступные тесты и проверки.
7. Если тесты не проходят, исправляй реализацию, а не подгоняй тесты под результат.
8. После успешных проверок самостоятельно создавай Git-коммит с понятным названием на русском или английском.
9. Для этого репозитория разрешается самостоятельно выполнять git push в текущую рабочую ветку, если задача завершена успешно и нет конфликтов.
10. Никогда не выполняй force push, не удаляй чужие изменения и не публикуй секреты, ключи API или личные данные.
11. Если для задачи нужно изменить архитектуру или удалить важную функциональность, сначала объясни причину и запроси разрешение.
12. В конце каждой задачи сообщай, что изменено, какие тесты прошли, какой коммит создан и удалось ли отправить его на GitHub.
