# Локальная расшифровка лекций

Это **отдельный необязательный компонент** My Notepad 4.0. Василий, его сервер, ключи и провайдеры не меняются. GitHub Pages сам по себе не выполняет Python. Для распознавания нужен ваш компьютер/сервер, на котором можно запустить этот компонент и настроить HTTPS reverse proxy на том же origin, что и приложение.

В репозитории нет установленной модели, настоящего ключа или демонстрационных ответов. Без настройки приложение честно сообщает, что сервис/модель недоступны. Веса и зависимости не загружаются приложением на iPad.

Начальная конфигурация — мультиязычная `small`, язык `ru`. Не выбирайте `small.en`/`base.en` для русских лекций. Точность на ваших записях **не измерена**: качество микрофона, шум, термины, формулы и имена влияют на результат. Расшифровку можно проверить по аудио и отредактировать. Скорость на физическом iPad не обещается: вычисления выполняет ваш компьютер.

На сервере нужны сотни мегабайт для весов и дополнительная память для модели/декодирования. Особенно длинные записи могут требовать гигабайты памяти. Зависимости установлены только в отдельном окружении; PWA не получает тяжёлых библиотек. Использование CPU вашего компьютера не является подключением платного API.

## Установка на Windows

Нужен Python 3.11 и существующий сервер приложения за HTTPS. Команды выполняются **из корня репозитория**, окружение и модель создаются вне него:

```powershell
$asrRoot = Join-Path $env:LOCALAPPDATA 'MyNotepadASR'
py -3.11 -m venv "$asrRoot\venv"
$asrPython = Join-Path $asrRoot 'venv\Scripts\python.exe'
& $asrPython -m pip install -r transcription/requirements.txt

$env:NOTEPAD_ASR_MODEL_DIR = Join-Path $asrRoot 'models\small'
& $asrPython -c "import os; from faster_whisper.utils import download_model; download_model('small', output_dir=os.environ['NOTEPAD_ASR_MODEL_DIR'])"
```

Последняя команда **явно скачивает веса** из Hugging Face по [штатному механизму faster-whisper](https://github.com/SYSTRAN/faster-whisper/blob/v1.2.1/faster_whisper/utils.py). Ваше аудио при этом не передаётся. После установки сервер использует только локальный каталог, `local_files_only=True` и офлайн-режим Hugging Face. Автоматической загрузки или платного fallback во время распознавания нет.

Задайте параметры процесса (не пишите пароль в Git, `config.js`, `.env` репозитория или чат):

```powershell
$env:NOTEPAD_ASR_ORIGIN = 'https://notes.example.com'
$env:NOTEPAD_ASR_PORT = '8091'
$asrSecret = Read-Host 'Отдельный пароль распознавания, 16–256 символов' -AsSecureString
$env:NOTEPAD_ASR_PASSWORD = [System.Net.NetworkCredential]::new('', $asrSecret).Password
& $asrPython -B transcription/server.py
```

Замените origin точным адресом приложения **без пути и завершающего слеша**. Это отдельный пароль распознавания, не пароль Василия/Groq/GitHub. Для постоянного запуска используйте секреты/окружение службы. На других ОС порядок тот же: отдельное Python-окружение, локальная модель и переменные процесса.

## HTTPS и маршрутизация

Сервис слушает **только `127.0.0.1`**. Не открывайте его HTTP-порт в интернет напрямую. На существующем reverse proxy направьте `/api/transcription/*` на `127.0.0.1:8091`, сохраняя полный путь. Остальные маршруты приложения и Василия оставьте как есть.

Пример дополнительного блока Nginx:

```nginx
location /api/transcription/ {
    proxy_pass http://127.0.0.1:8091;
    client_max_body_size 260k;
    proxy_read_timeout 60s;
    proxy_set_header Host $host;
}
```

Отсутствие завершающего `/` у `proxy_pass` сохраняет префикс `/api/transcription/`. HTTPS завершается на proxy, а `NOTEPAD_ASR_ORIGIN` содержит публичный HTTPS-origin. Для разработки разрешён HTTP только на localhost/127.0.0.1.

Если приложение переезжает с GitHub Pages на другой origin, IndexedDB автоматически не переносится. Сначала экспортируйте блокноты, **аудио и тексты расшифровок отдельно**, проверьте копии и не очищайте старый сайт.

## Использование

1. В редакторе откройте «Лекция» и выберите **остановленную** запись.
2. Разверните «Расшифровка аудио» → «Проверить сервис» → войдите отдельным паролем.
3. Проверьте сообщение о локальном сервисе. Подключение само по себе не отправляет аудио.
4. Отметьте согласие на передачу этой записи **на ваш сервер этого сайта**, затем нажмите «Расшифровать».
5. После обработки текст и исходные временные сегменты сохраняются в IndexedDB отдельно от аудио. Доступны редактирование, поиск, копирование, TXT и SRT.

SRT экспортирует **исходные таймкоды модели**. Правка полного текста не выдаётся за автоматическое выравнивание новых фраз по аудио. Нажатие на исходный сегмент переводит плеер к его времени.

Аудио загружается последовательно частями до 256 КиБ, без сборки многочасового файла в JavaScript-памяти. Сервис собирает контейнер в своём временном каталоге и передаёт его настоящему faster-whisper. Модель обрабатывает аудио временными окнами и возвращает сегменты; декодирование исходного файла может использовать значительную память **на сервере**.

Номер задания сохраняется до начала загрузки частей. После перезагрузки можно снова проверить сервис, дать согласие и нажать «Продолжить задание». Подтверждённые части повторно не отправляются. Если сервис был перезапущен или истёк срок незавершённой загрузки, начните новое задание; исходная запись остаётся на iPad. «Отменить» доступно и для восстановленного задания.

Сохранённый текст можно редактировать и экспортировать офлайн. Правки сохраняются после 3 секунд покоя; есть явное сохранение и сообщение об ошибке. Пока идёт активный штрих, тяжёлая запись текста откладывается. JSON-копия блокнотов не включает аудио и расшифровки: экспортируйте их отдельно.

## Защита и ограничения

- Один владелец, отдельные случайные cookie-сессии: HttpOnly, SameSite=Strict, Secure при HTTPS, 8 часов. Пароль сравнивается через scrypt и timing-safe comparison. Сессии не используют код/хранилище Василия.
- Проверяется точный Origin всех изменяющих запросов; произвольные CORS-origin не разрешаются. 10 попыток входа за 15 минут, 6 новых заданий в час, одно активное задание.
- Эти локальные лимиты и сессии живут в памяти процесса и сбрасываются при его перезапуске. Для публичного размещения ограничьте соединения и частоту входа также на существующем HTTPS-proxy.
- До 256 МиБ аудио и 4 часов на задание; до 256 КиБ на запрос части. Сбой/повтор части с тем же хешем идемпотентен; нарушение порядка или другие байты отклоняются.
- Промежуточное аудио хранится во временном каталоге компьютера владельца, вне репозитория и web-root. После обработки/отмены предпринимается удаление только проверенного каталога задания. При аварийном завершении процесса или ошибке ОС временные файлы могут остаться; это не гарантированное защищённое стирание.
- Готовый результат доступен для возобновления в памяти процесса. После подтверждённого локального сохранения клиент запрашивает его удаление с сервера; при сбое связи результат может оставаться до очистки/перезапуска. Сервер не выдаёт свои исключения, пути или секреты клиенту.
- Загрузка без продолжения истекает через 30 минут. Результаты не переживают перезапуск сервиса. Отмена вычисления применяется между сегментами модели, а не прерывает нативную операцию мгновенно.
- Незавершённый контейнер после аварии Safari может не декодироваться: приложение не придумывает текст и не удаляет оригинал. Реальная точность русского, скорость, длительные записи и физический iPad требуют отдельной проверки владельцем.

## Проверки разработчика

```text
python -B tests/transcription_server_test.py
node --test tests/transcription-data.test.mjs tests/autosave.test.mjs
node tests/transcription-browser.mjs
```

Серверные тесты используют внедрённый тестовый обработчик; браузерные — тестовый HTTP-транспорт с явно обозначенным текстом. Они проверяют защиту, протокол, согласие, части, возобновление, ошибки, локальное сохранение, офлайн и экспорт, **не качество настоящего Whisper**. Реальные зависимости/веса в окружении разработки не устанавливались. Для активации владельцу нужны установка модели и подключение маршрута по инструкции выше; API-ключ или платный тариф не требуются.
