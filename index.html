Подключение Василия

Для этого приложения ChatGPT Plus и OpenAI API — разные сервисы: подписка Plus не оплачивает запросы нашего серверного адаптера к API.

Здесь указывается только адрес сервера. Не вставляйте API-ключи, пароли или токены.

  1. Разместите серверный адаптер за HTTPS с серверной авторизацией и постоянными квотами.
  2. Задайте OPENAI_API_KEY и OPENAI_MODEL в окружении сервера; разрешите точный адрес этого приложения.
  3. Подключите POST /api/assistant и GET /api/assistant/status, настройте вход через защищённую сессию.
  4. Укажите публичный адрес выше, войдите на своём сервере и проверьте подключение.

Инструкция по развёртыванию · Оплата OpenAI API

Материалы передаются серверу и OpenAI только после нажатия «Отправить». Передаются первые 40 000 символов текста. Текст со сканов без OCR недоступен; можно отправить изображение страницы. Распознавание почерка не гарантируется.
