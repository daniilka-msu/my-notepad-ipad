Подключение Василия

Основной вариант — бесплатный тариф GroqCloud для текстовых вопросов. ChatGPT Plus и API — разные сервисы; подписка Plus не нужна для Groq. Переход на платный тариф приложение не выполняет.

Здесь указывается только адрес сервера. Не вставляйте API-ключи, пароли или токены.

  1. Разместите серверный адаптер за HTTPS с серверной авторизацией и постоянными квотами.
  2. Задайте GROQ_API_KEY и пароль входа NOTEPAD_PASSWORD только в окружении сервера; используйте его бесплатный тариф.
  3. Запустите node server/app.mjs по инструкции: сервер обслуживает PWA, вход и защищённые запросы на одном сайте.
  4. Укажите публичный адрес выше и нажмите «Проверить подключение». Если сервер поддерживает вход, ниже появится форма пароля.
