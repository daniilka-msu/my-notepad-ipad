# Подключение ИИ

GitHub Pages обслуживает статические файлы и не может безопасно выполнять запросы с API-ключом. По умолчанию `config.js` содержит пустой `aiEndpoint`; интерфейс честно показывает «ИИ не подключён». Никаких тестовых ответов в продукте нет.

`ai-handler.mjs` — серверный адаптер Node.js 22+. Подключите его к HTTPS-серверу по маршрутам `POST /api/assistant` и `GET /api/assistant/status`. Фабрика требует `authorize(req)` (проверка серверной сессии), `consumeQuota(user)` (лимит пользователя) и точный `allowedOrigin`. Пока эти зависимости не переданы, адаптер отказывается запускаться. Для внешнего домена нужны защищённые HttpOnly cookie и корректная серверная сессия; ограничения Safari на сторонние cookie учитывайте при размещении.

Ключ `OPENAI_API_KEY` и имя поддерживаемой текстово-визуальной модели `OPENAI_MODEL` передаются **только в окружение серверного процесса** или менеджер секретов хостинга. Не включайте их в репозиторий, HTML, JavaScript клиента, localStorage и резервные копии. Настройте лимиты затрат на сервере/в проекте OpenAI; API может оплачиваться отдельно. Здесь не устанавливаются ключи, модель, учётные записи и платные ресурсы.

После настройки сервера укажите его публичный URL в `config.js`. Ответ на `GET …/status`: `{ "connected": true }`; ответ на POST: `{ "text": "…" }`. Клиент отправляет историю `{messages:[{role,content}]}` и, только по выбору пользователя, `pageImage` (JPEG data URL) и/или `documentText`. Для текста документа действует лимит 40 000 символов, что явно учитывайте при анализе больших документов. Ответ вставляется в новые страницы, исходный конспект не заменяется. Чат существует в памяти до перезагрузки.

Официальные источники: [аутентификация и серверное хранение ключей](https://developers.openai.com/api/reference/overview), [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create). Адаптер использует Responses API, без сохранения ответа (`store: false`). Не отправляйте ключ браузеру. Перед включением для пользователей добавьте проверенную аутентификацию, долговечные квоты, политику обработки документов и проверьте интеграцию с реальным API.
