# My Notepad — Editor Overhaul

21 октября 2026. Исходный коммит: 09cb4c2.

## Этап 1. Диагностика

Приложение использует обычный JavaScript, не React. Высокочастотный ввод не обновляет дерево компонентов. Уже работают: requestAnimationFrame, coalesced pointermove, отдельный активный слой, ограниченные растровые поверхности, кэш завершённых штрихов, документная сетка, IndexedDB и очередь сохранения после паузы. Бесконечные документы используют пространственный индекс, ленивую загрузку и ограниченный кэш; старые заметки остаются в прежнем формате.

Подтверждённые недостатки исходников:

1. `Editor` при каждом открытии страниц последовательно вызывает `Documents.compose` для всех страниц. `compose` создаёт полноразмерный canvas, временно переключает глобальный документ и вызывает `paint(false)` и `paint()`; это затрагивает кэш рабочего редактора даже для маленькой миниатюры.
2. Pointermove читает накопленные события, pointerup — только последнюю координату. Последние реальные движения могут остаться в coalesced-событиях отпускания.
3. Защита от выделения текста охватывает не весь интерфейс. Сторонний стилус, передающий touch, может запускать выделение подписи вне панели инструментов.
4. Редакторы кистей и страниц модальные. Это мешает сопоставлять параметры с листом и пользоваться навигацией без большого окна.
5. Длинный карандаш остаётся дорогим: каждый кадр повторно рисует отдельные зёрна. Предыдущие измерения не подтверждают 60 FPS для этого случая; нельзя объявлять проблему решённой только после изменения CSS.

Свежий контрольный прогон: `benchmarks/overhaul-before.json`, сценарии 0/100/1000/5000/10000 штрихов, изображения и бесконечные документы. Время зависит от настольного окружения; физический iPad не измерялся.

## Последовательность

2. Новая компоновка окна: компактная навигация, быстрые цвета/толщины, немодальные параметры активного инструмента и отдельная панель страниц. Сохранить идентификаторы и обработчики существующих инструментов.
3. Ввод: обработка последних накопленных событий, достоверные данные пера, защита интерфейса от выделения. Новые регрессии для pen/touch, быстрых штрихов и отпускания.
4. Инструменты: быстрый выбор двух ластиков, параметры и пресеты; не дублировать лассо, фигуры, текст и изображения. Проверить общую историю.
5. Страницы: независимый ограниченный рендер миниатюр, видимые страницы, отменяемые удаление/дублирование/перестановка; сохранить три формата документов.
6. Интеграция, офлайн, сравнение экспорта, измерения, README и changelog, публикация.
